# 作業日報＆業務改善システム (nippo-app)

社員が日々の業務実績を入力し、**「業務の改善と効率化」**のアイデアやムダの削減策を組織全体で集積・推進するためのWebアプリケーションです。

---

## 🌟 主な機能・特長

1. **改善・効率化に直結するフォーマット**
   * 「本日の業務内容」「業務改善・効率化の気付き・提案（最重要）」「明日の予定」「業務効率実感（5段階）」の明快な構成
   * 改善カテゴリのワンタップ挿入（`[マニュアル化が必要]`、`[確認の重複を解消]`、`[ツール活用・自動化]` など）
   * スマートフォン・PC対応の音声入力（マイクボタン）で入力負担を最小化
2. **Supabase による安全なユーザー認証**
   * メールアドレス ＋ パスワードによるログイン／新規登録
   * **パスワード忘れ対応**: パスワード再設定リンクメールの自動送信とパスワード再設定画面を完備
3. **クラウドDB保存 & 過去履歴閲覧**
   * Supabase PostgreSQL に即時保存（Row Level Security により本人のデータのみ安全に閲覧・更新）
   * 過去の日報・改善提案履歴を一覧でいつでも振り返り可能

---

## 🚀 セットアップ手順

### 1. Supabase の準備
1. [Supabase](https://supabase.com/) で新規プロジェクトを作成します。
2. 左メニューの **「SQL Editor」** を開き、本リポジトリ内の `supabase_schema.sql` の内容を貼り付けて **「Run」** を実行します（テーブルとセキュリティポリシーが自動生成されます）。
3. 左メニューの **「Project Settings」>「API」** から、以下をコピーします：
   * `Project URL`
   * `anon public key`

### 2. アプリの起動・設定
1. `index.html` をブラウザで直接開くか、ローカルサーバーまたは Cloudflare Pages 等にホスティングします。
2. 画面右上の **「⚙️ 設定」** ボタンをクリックし、上記で取得した `Project URL` と `anon public key` を入力して保存します。
3. これでログイン・新規登録・日報作成がすぐにご利用いただけます。
